# 首页素材来源

- `paper.jpg`：为本次首页生成的皱纸纹理，裁掉白色边缘后本地使用。
- `star.jpg`：为本次首页生成的铬银镶钻星形装饰，非模板图片。
- 图像使用 Trae 的文本生成图片服务；没有引用或热链 StrawPage 模板里的图片、人物或项目内容。
- `../fonts/caveat.ttf`：Google Fonts 的 Caveat，用于手写正文。许可证为 `../fonts/Caveat-OFL.txt`。
- `../fonts/unifraktur-maguntia.ttf`：Google Fonts 的 UnifrakturMaguntia，用于招牌与票券标题。许可证为 `../fonts/UnifrakturMaguntia-OFL.txt`。
- `../fonts/japanese.otf`：沿用现有日文字体，不更换工具页字体。
- 胶带、夹子、纸张撕边、电视机外壳、扫描线与闪光通过 CSS 绘制，不依赖外部图片。
