# Chez you7n 拼贴重设计实施计划

**目标：** 以用户确认的 StrawPage 截图为材质和构图参考，将首页改为真实物件式拼贴，保留全部内容和多语言问候。

**架构：** 首页使用独立 `homepage.css`。原 `styles.css` 及工具路由保持独立。`script.js` 保留 31 条问候及默认 200/100/2000ms 节奏，增加可暂停的播放控制和无打字动画的低动态循环。

**技术栈：** 原生 HTML/CSS/JS、Node 内置测试、浏览器实测。图片素材由指定图像生成接口生成并本地保存，字体保留跨文字系统回退。

## 视觉与内容

- 横线纸底、皱纸和撕边页、蓝色夹子、半透明胶带构成统一桌面。
- 亮粉与亮蓝倾斜招牌是品牌焦点；粉色小电视承载原多语言动画。
- About 是夹住的纸页，四个 Projects 使用尺寸和材质不同的纸片。
- Tools 是独立的活页纸清单，Toys 是一张单独票券，不再使用同构卡片网格。
- 装饰物不携带项目事实；正文保持 DOM 文本，装饰不遮挡链接。
- 手机重新编排为窄幅拼贴，降低倾斜和重叠，保持文字不被裁切。

## 执行与验收

1. 更新 `tests/homepage.test.mjs`，锁定独立样式、电视播放控制、所有事实描述、链接、日期与原语言列表；先执行 `node --test tests/*.test.mjs` 观察新检查失败。
2. 创建 `homepage.css`、更新 `index.html`；现有 `/kana2IPA`、`/speciesDetect`、`/speaker` 不改功能，不使用新首页样式。
3. 在浏览器中验证暂停、恢复、低动态循环、RTL/CJK 和完整循环；所有语言文本保留。
4. 使用 1440px、820px、390px 和 320px 视口检查横向溢出、字体、装饰与正文重叠，并截图查看而非仅凭 DOM 快照判定视觉。
5. 再次运行 Node 测试，检查本地图片和字体 HTTP 返回及控制台错误。
